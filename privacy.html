Privacy Policy

Last updated: October 5, 2026

Purpose

rclone-bot is a personal application used by its owner to connect an Oracle Cloud server with Google Drive.

Google Drive Access

With the owner's authorization, the application can read, upload, modify, organize, and delete files in Google Drive.

Data Storage

Files may be transferred between Google Drive and the owner's Oracle Cloud server. OAuth credentials are stored in the owner's rclone configuration.

Data Usage

The application is intended for personal file management and automation, not public access.

Revoking Access

Access can be revoked through Google Account security settings.

Contact

Contact the application owner through the associated GitHub profile.
